None of this is hypothetical for a live-service game. Ad platforms already run bandit-style optimization on creative rotation, shifting spend toward whichever ad variant is converting best in something close to real time. Store and offer placement, matchmaking parameters, even which tutorial variant a new player sees — anywhere a studio can cheaply swap between a handful of options and cheaply observe the outcome, the honest framing is a bandit problem whether or not anyone on the team calls it that. The uncomfortable part is that this only works when switching is genuinely cheap: a feature that took a sprint to build and cannot be un-shipped mid-quarter is not an arm you can pull and retract, which is exactly why this essay uses ad campaigns instead of features as its running example.
